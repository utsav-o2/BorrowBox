# BorrowBox

BorrowBox is my Web Technology project developed using React.

## Project Idea
Students can browse items shared by other students
and request to borrow them.

## Technologies
- React
- JavaScript
- HTML
- CSS

## Planned Features
- Home page
- Item cards
- Search items
- Category filtering
- Borrow button
- Add item form
