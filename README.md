# BorrowBox

BorrowBox is a small React project that we made for our Web Technology elective subject.

The idea behind this website is simple. Sometimes students need things like calculators, books, or chargers for a short time. Instead of buying them, they can borrow these items from other students.

## Features

- A simple homepage with navigation links
- View items available for borrowing
- Borrow an item or cancel a request
- Add new items by entering their details
- About section with basic project information
- Simple and responsive design

## Technologies Used

- React JS
- JavaScript
- HTML
- CSS
- Vite

## How to Run

1. Download the project from GitHub.
2. Open the BorrowBox folder in VS Code.
3. Open the terminal.
4. Run `npm install` to install the required packages.
5. Run `npm run dev` to start the website.
6. Open the localhost link shown in the terminal.

## About the Project

We made this project to practice React and improve our understanding of web development.

While making BorrowBox, we worked with React components, state, forms, buttons, and CSS styling.

The website is mainly focused on basic front-end functionality, so we haven't added a database or login system.

**Note:** Items added through the form and borrow requests are temporary. They reset when the page is refreshed.
